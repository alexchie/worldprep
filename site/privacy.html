隱私權政策

最後更新：2026-10-04

適用範圍

「世界先修課」影片製作工具（以下稱本工具）僅供頻道經營者本人使用，用於自動製作紀錄片影片並存放到經營者本人的 Google 雲端硬碟。本工具不提供給其他使用者，也不對外蒐集任何人的資料。

存取的 Google 資料

本工具經經營者本人授權後，使用 Google Drive API 存取經營者本人的 Google 雲端硬碟，用途僅限於：

  • 將製作完成的影片、縮圖、字幕與說明文字上傳到經營者指定的資料夾；
  • 讀寫本工具自己的工作狀態檔案。

本工具不讀取、分析或修改該資料夾以外的檔案，也不將任何 Google 使用者資料分享、出售或提供給第三方，亦不用於廣告或訓練人工智慧模型。

資料保存與刪除

授權憑證僅以加密方式保存在經營者本人控制的環境中。經營者可隨時到 Google 帳戶的「第三方應用程式與服務」頁面撤銷本工具的存取權。

Google API 服務使用者資料政策

本工具對 Google API 所取得資訊的使用與傳輸，遵守 Google API Services User Data Policy，包括 Limited Use 要求。

聯絡方式

如有任何問題，請透過 Google 授權畫面上顯示的支援電子郵件地址與我們聯繫。
